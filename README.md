# Campus Viva

Protótipo acadêmico interativo criado para demonstrar uma solução de engajamento universitário.

## Problema
Às quintas-feiras, parte dos alunos deixa o campus durante o período de aula e permanece fora por um período prolongado.

## Solução
O Campus Viva propõe atividades, gamificação, check-in por QR Code, recompensas e indicadores de engajamento para criar motivos reais para os alunos permanecerem no campus.

## Como executar localmente
Basta abrir o arquivo `index.html` no navegador.

## Como publicar no GitHub Pages
1. Crie um repositório no GitHub.
2. Envie `index.html`, `style.css` e `app.js` para a raiz do repositório.
3. No GitHub, abra **Settings > Pages**.
4. Em **Build and deployment**, escolha **Deploy from a branch**.
5. Selecione a branch `main` e a pasta `/ (root)`.
6. Salve.
7. O GitHub mostrará o endereço público do site.

Nenhum banco de dados ou servidor é necessário para esta versão.
